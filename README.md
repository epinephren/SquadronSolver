# SquadronSolver

A Dalamud plugin that analyzes your Grand Company Squadron roster and recommends the best party for the currently selected mission.

## Features

* Reads mission requirements directly from the Squadron Mission window
* Reads Squadron member stats directly from the Squadron Member List
* Calculates the best available 4-member party
* Displays mission success status
* Shows missing STR, MEN, and TAC requirements
* Works with live game data
* Language-independent by using in-game UI data

## Usage

Open both:

* Squadron Missions
* Squadron Member List

Then use:

```text
/squadsolver
```

or

```text
/sqs
```

The plugin will analyze the selected mission and recommend the strongest available party from your roster.

## Requirements

* Grand Company Squadron unlocked
